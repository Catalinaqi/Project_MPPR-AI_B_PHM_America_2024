# A Design Science Approach Comparing Ensemble Learning and Artificial Neural Networks for Uncertainty-Aware Helicopter Turbine Engines Health Monitoring

## Panoramica del Progetto

Questo lavoro presenta lo sviluppo di un sistema di monitoraggio della salute dei motori a turbina degli elicotteri con quantificazione dell'incertezza, concentrandosi sul miglioramento della disponibilità operativa e sulla riduzione dei costi di manutenzione.

## Problema Affrontato

Il progetto affronta il problema critico della quantificazione dell'incertezza nel rilevamento dei guasti basato sui dati e nella prognostica, essenziale per aumentare l'affidabilità del sistema nei motori a turbina degli elicotteri.

## Metodologia

Il progetto segue un ciclo di sviluppo iterativo utilizzando l'approccio Design Science Research, incorporando molteplici tecniche per:

- **Elaborazione dei dati**: generazione di caratteristiche polinomiali e pulizia dei dati
- **Sviluppo del modello**: ensemble learning e reti neurali artificiali
- **Valutazione**: K-fold cross-validation e group-fold cross-validation

## Algoritmi Utilizzati

### Classificazione (Rilevamento Guasti)
- **Random Forest**: modello ensemble con 100 alberi decisionali
- **Architettura a cascata**: utilizza il margine di coppia previsto come caratteristica aggiuntiva
- **Rete Neurale Artificiale Multi-task**: con funzione di attivazione ReLU e perdita binary cross-entropy

### Regressione (Predizione del Margine di Coppia)
- **Bagged Linear Regression**: ensemble di 100 regressioni lineari con caratteristiche polinomiali di secondo grado
- **Random Forest**: come modello baseline
- **Rete Neurale Artificiale Multi-task**: con perdita negative log-likelihood per regressione probabilistica con incertezza

## Formule Matematiche Utilizzate

### 1. **Margine di Coppia (Equazione 1)**
```
torque_margin(%) = 100 × (torque_measured - torque_target) / torque_target
```
Calcola il margine di coppia come indicatore della salute del motore, confrontando la coppia misurata con la coppia obiettivo.

### 2. **Punteggio di Classificazione (Equazione 2)**
```
score_ci = {
    ci                    se ŷi = yi
   -ci                    se ŷi = 1, yi = 0
   -4ci - ci              se ŷi = 0, yi = 1
}
```
Valuta il compito di rilevamento dei guasti considerando la previsione di classe (ŷi), la classe vera (yi) e il valore di confidenza (ci ∈ [0.0, 1.0]).

### 3. **Punteggio di Regressione (Equazione 3)**
```
score_ri = (1/√(2πsi²)) × exp(-(ri - li)² / (2si²))
```
Valuta la regressione probabilistica del margine di coppia utilizzando una distribuzione Gaussiana, dove:
- ri = etichetta vera
- li = previsione di posizione (media)
- si = scala (deviazione standard)

### 4. **Punteggio Finale (Equazione 4)**
```
score = (1/N) × Σ(i=1 to N) [(score_ci + score_ri) / 2]
```
Calcola la media dei punteggi di classificazione e regressione per tutti i campioni valutati.

### 5. **Rapporto di Sbilanciamento (Equazione 5)**
```
Imbalance_ratio = # Healthy_Samples / # Faulty_Samples
```
Calcola il rapporto di sbilanciamento tra campioni sani e difettosi (risultato: 1.48).

### 6. **Coppia Obiettivo (Equazione 6)**
```
torque_target = (100 × torque_measured) / (100 + torque_margin)
```
Calcola la coppia obiettivo dalla coppia misurata e dal margine di coppia. Questa è l'inversa dell'Equazione 1 e viene utilizzata per convertire le previsioni.

**Nota**: Queste formule costituiscono il quadro matematico fondamentale per il sistema di monitoraggio della salute con quantificazione dell'incertezza sviluppato nel lavoro.

## Soluzione Finale

La soluzione finale consiste in un **modello ensemble a cascata** che combina:

1. **Bagged Linear Regression** costruita su caratteristiche polinomiali per la predizione del margine di coppia
2. **Random Forest** per il rilevamento dei guasti, utilizzando il margine di coppia previsto come caratteristica aggiuntiva

## Risultati

Il modello dimostra prestazioni robuste, raggiungendo:
- **Test score**: 0.955719
- **Validation score**: 0.886953

Questi risultati dimostrano l'efficacia dei metodi di machine learning con quantificazione dell'incertezza nei sistemi di monitoraggio della salute.

## Dataset

Il dataset è composto da sette motori dello stesso tipo e modello:
- **Training set**: 742,625 campioni (4 motori)
- **Test set**: 21,436 campioni
- **Validation set**: 21,436 campioni

### Caratteristiche Misurate
- Temperatura dell'aria esterna (OAT)
- Temperatura media del gas (MGT)
- Potenza disponibile (PA)
- Velocità indicata dell'aria (IAS)
- Potenza netta (NP)
- Velocità del compressore (NG)
- Coppia misurata (TRQ)

## Distribuzione di Probabilità

È stata utilizzata la **distribuzione Gaussiana (PDF)** per la regressione probabilistica, con una deviazione standard minima di 0.4 per garantire robustezza nelle previsioni.
