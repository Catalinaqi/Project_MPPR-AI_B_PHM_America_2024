# Robust Health Condition Prediction of Helicopter Turboshaft Engines Using Ensemble Machine Learning Models

## Panoramica del Progetto

Questo documento presenta un approccio ensemble innovativo che combina molteplici algoritmi di machine learning per fornire predizioni robuste dello stato di salute dei motori turboshaft degli elicotteri (nominale o difettoso) utilizzando dati operativi. La salute del motore è valutata attraverso il margine di coppia, definito come la differenza percentuale tra i valori di coppia misurati e obiettivo.

## Problema Affrontato

Il progetto affronta due compiti chiave per il monitoraggio della salute dei motori turboshaft degli elicotteri:
1. **Classificazione binaria dello stato di salute del motore**: determinazione se il motore è nominale (sano) o difettoso
2. **Regressione probabilistica per stimare il margine di coppia**: stima del margine di coppia come funzione di densità di probabilità (PDF)

I metodi tradizionali di manutenzione si basano pesantemente su ispezioni programmate, che possono portare a tempi di inattività non necessari o mancata rilevazione di guasti in fase iniziale. Questo studio propone un approccio basato sui dati che sfrutta i dati operativi per valutare la salute del motore in tempo reale e abilitare strategie di manutenzione predittiva.

## Metodologia

L'approccio proposto utilizza un **framework ensemble di machine learning** strutturato in fasi chiave:

### 1. Analisi Esplorativa dei Dati (EDA)

**Parametri Misurati Critici** (7 parametri):
- **OAT (Outside Air Temperature)**: temperatura dell'aria esterna, influenza la temperatura dell'aria in ingresso al motore
- **MGT (Mean Gas Temperature)**: temperatura media del gas, indicatore chiave dello stato termico del motore
- **PA (Available Power)**: potenza disponibile, riflette l'output potenziale massimo del motore
- **IAS (Indicated Airspeed)**: velocità indicata dell'aria, rappresenta la velocità dell'aeromobile
- **NP (Net Power)**: potenza netta, output di potenza effettivo dopo le perdite di sistema
- **NG (Compressor Speed)**: velocità del compressore, regola il flusso d'aria e la pressione
- **Trq_measured**: coppia del motore misurata

**Feature Engineering**:
- Calcolo della coppia obiettivo (target torque) utilizzando correlazioni empiriche basate sui sei parametri operativi
- Calcolo del margine di coppia come indicatore chiave della salute del motore

**Caratteristiche del Dataset**:
- **Training set**: 742,625 punti dati operativi da 4 motori turboshaft identici
- Dati mescolati per evitare bias di sequenza
- 443,207 punti dati sani e 299,418 punti dati difettosi
- **Test set**: 24,160 punti dati (3.25%) selezionati in base alla distanza euclidea minima dai punti sconosciuti
- **Validation set**: ~20,000 punti dati con stati sconosciuti

**Insights dall'EDA**:
- Correlazione negativa moderata tra 'Faulty' e OAT (-0.34)
- Forte correlazione negativa tra 'Faulty' e margine di coppia (-0.61)
- Correlazione positiva tra 'Faulty' e PA (0.34)
- Multi-collinearità osservata in diversi parametri, indicando relazioni non lineari e interdipendenti

### 2. Regressione con Space Filling

**Gaussian Process Regression (GPR)**:
- Utilizzato per predire la coppia obiettivo (design torque) basandosi sui dati del motore turboshaft
- Fornisce stime probabilistiche (media e varianza predittive)
- Ideale per la quantificazione dell'incertezza

**Strategia Space-Filling**:
- **Approccio Max-min**: selezione adattiva di nuovi punti di training massimizzando la distanza minima tra un nuovo punto e tutti i punti esistenti
- Campionamento uniforme dello spazio di progettazione evitando il clustering di punti
- 2,000 punti selezionati casualmente come dati di training iniziali
- 18,000 punti aggiuntivi selezionati sequenzialmente usando il criterio Max-min
- Totale: 20,000 punti di training per il modello GPR

**Kernel**:
- **Matérn kernel** con parametro di smoothness µ = 3/2
- Funzione di covarianza flessibile per modellare dati con smoothness variabile

**Approccio di Predizione**:
- Predizione della coppia obiettivo intermedia come output del modello di regressione
- Calcolo del margine di coppia utilizzando l'equazione
- Riduzione della perdita di informazioni e migliore cattura della relazione input-output

### 3. Modello Ensemble per la Classificazione

**Architettura Ensemble**:
L'ensemble model consiste di **base learners** e un **meta learner**:

**Base Learners** (4 modelli):

1. **Convolutional Neural Network (CNN) 1D**
    - Architettura: 2 layer convoluzionali (32 e 64 filtri, kernel size 3)
    - Flattening layer + dense layer (50 neuroni)
    - Output layer: 1 neurone con attivazione sigmoid
    - Ottimizzatore: Adam (learning rate 0.001)
    - Loss function: binary cross-entropy
    - Early stopping con patience di 10
    - Capacità di catturare gerarchie spaziali nei dati strutturati

2. **Multi-Layer Perceptron (MLP)**
    - Architettura: 3 hidden layers (50, 100, 50 neuroni)
    - Funzione di attivazione: ReLU
    - Output layer: 1 neurone con attivazione sigmoid
    - Ottimizzatore: Adam (learning rate 0.001)
    - Loss function: binary cross-entropy
    - Early stopping con patience di 10
    - Capacità di approssimazione universale per relazioni non lineari

3. **XGBoost (Extreme Gradient Boosting)**
    - Learning rate: 0.1
    - Numero di estimatori: 500
    - Profondità massima dell'albero: 5
    - Metrica di valutazione: 'logloss'
    - Framework di gradient boosting potente per efficienza e accuratezza

4. **AdaBoost (Adaptive Boosting)**
    - Base estimator: decision tree (profondità massima 4)
    - Numero di estimatori: 300
    - Learning rate: 0.1
    - Algoritmo: 'SAMME'
    - Adaptive boosting per migliorare le performance su campioni difficili

**Meta Learner**:
- **Logistic Regression**
    - Parametro di regolarizzazione C: 0.9
    - Solver: 'liblinear'
    - Iterazioni massime: 400
    - Random state: 42 (per riproducibilità)
    - Aggrega le predizioni dai base models
    - Scelto per semplicità e interpretabilità

**Input del Modello di Classificazione**:
- OAT, MGT, PA, IAS, NP, NG
- Margine di coppia ottenuto dal processo di regressione precedente

**Output**:
- Classe binaria dello stato di salute del motore (0 = sano, 1 = difettoso)

### 4. Selezione del Set di Training Ottimale

**Strategia di Selezione**:
- Filtraggio dei punti con la distanza euclidea più piccola a un certo livello
- Sperimentazione con diverse dimensioni del training dataset
- Identificazione della dimensione ottimale: ~190,000 punti dati
- Training finale su 189,782 punti dati filtrati

**Motivazione**:
- Evitare l'overfitting su dati bilanciati in modo errato nello spazio operativo
- Migliorare la capacità di generalizzazione del modello
- Ridurre i bias dovuti a punti dati da spazi operativi diversi

### 5. Selezione della Funzione di Riferimento

**Strategia di Selezione del Set di Riferimento**:
- Per ogni punto dati non visto, viene definito un set di riferimento
- Confronto delle performance relative dei modelli
- Selezione del modello con le migliori prestazioni per la predizione finale

## Algoritmi Utilizzati

### Regressione (Stima del Margine di Coppia)
- **Gaussian Process Regression (GPR) con Matérn Kernel**
    - Kernel: Matérn con µ = 3/2
    - Strategia Space-Filling: approccio Max-min
    - Distribuzione normale come PDF per le predizioni
    - Quantificazione dell'incertezza intrinseca
    - Training su 20,000 punti selezionati strategicamente

### Classificazione (Predizione dello Stato di Salute)
Approccio ensemble con architettura di stacking:

1. **CNN 1D** - per catturare pattern spaziali
2. **MLP** - per relazioni non lineari complesse
3. **XGBoost** - per gradient boosting efficiente
4. **AdaBoost** - per adaptive boosting su campioni difficili
5. **Logistic Regression** (Meta Learner) - per aggregare le predizioni

### Tecniche di Campionamento
- **Max-min Space-Filling**: campionamento sequenziale per copertura completa dello spazio di input

### Tecniche di Ottimizzazione
- **Adam Optimizer**: per CNN e MLP
- **Gradient Boosting**: per XGBoost
- **Adaptive Boosting**: per AdaBoost
- **Early Stopping**: per prevenire l'overfitting

## Formule Matematiche Utilizzate

### 1. **Margine di Coppia (Equazione 1)**
```
Trq_margin = 100 × ((Trq_measured - Trq_target) / Trq_target)
```
Dove:
- Trq_margin = margine di coppia (%)
- Trq_measured = coppia misurata
- Trq_target = coppia obiettivo (design torque)

Il margine di coppia è definito come la differenza percentuale tra i valori di coppia misurati e obiettivo, e serve come indicatore chiave della performance e salute del motore. Quando il margine di coppia scende sotto una certa soglia, indica costantemente una probabilità del 100% di guasto del motore.

### 2. **Criterio Max-min per Space-Filling**
```
x_new = argmax_x min_{x_i ∈ X_train} ||x - x_i||_2
```
Dove:
- x_new = nuovo punto di training da aggiungere
- X_train = insieme di tutti i punti di training correnti
- ||·||_2 = norma L2 (distanza euclidea)
- argmax_x = argomento che massimizza la funzione

Questo metodo assicura che i nuovi punti siano localizzati nell'area più "vuota" dello spazio di training, campionando uniformemente lo spazio di progettazione ed evitando il clustering di punti.

### 3. **Matérn Kernel per GPR**
```
k_Matérn(r) = (2^(1-ν) / Γ(ν)) × (√(2ν) × r / ℓ)^ν × K_ν(√(2ν) × r / ℓ)
```
Dove:
- r = distanza tra due punti
- ν = parametro di smoothness (µ = 3/2 in questo studio)
- ℓ = parametro di length scale
- Γ(·) = funzione Gamma
- K_ν(·) = funzione di Bessel modificata del secondo tipo di ordine ν

Per ν = 3/2, la forma semplificata è:
```
k_Matérn_3/2(r) = (1 + √3 × r / ℓ) × exp(-√3 × r / ℓ)
```

Il Matérn kernel è una funzione di covarianza particolarmente popolare per la sua flessibilità nel modellare dati con smoothness variabile.

### 4. **Gaussian Process Regression (GPR) - Predizione**
```
μ(x*) = k(x*)ᵀ × (K + σ²I)^(-1) × y
σ²(x*) = k(x*, x*) - k(x*)ᵀ × (K + σ²I)^(-1) × k(x*)
```
Dove:
- μ(x*) = media predittiva al punto x*
- σ²(x*) = varianza predittiva al punto x*
- k(x*) = vettore di covarianza tra x* e i punti di training
- K = matrice di covarianza dei punti di training
- σ² = varianza del rumore
- I = matrice identità
- y = valori target di training

GPR fornisce stime probabilistiche, trattando ogni predizione come una distribuzione anziché un singolo punto.

### 5. **Binary Cross-Entropy Loss (per CNN e MLP)**
```
L = -1/N × Σ[y_i × log(ŷ_i) + (1 - y_i) × log(1 - ŷ_i)]
```
Dove:
- N = numero di campioni
- y_i = etichetta vera (0 o 1)
- ŷ_i = probabilità predetta
- L = loss totale

### 6. **XGBoost Loss Function (Log Loss)**
```
L = -Σ[y_i × log(p_i) + (1 - y_i) × log(1 - p_i)]
```
Dove:
- y_i = etichetta vera
- p_i = probabilità predetta dal modello
- L = log loss (binary cross-entropy)

### 7. **AdaBoost - Aggiornamento dei Pesi**
```
w_i^(t+1) = w_i^(t) × exp(α_t × I(y_i ≠ h_t(x_i)))
α_t = 0.5 × log((1 - ε_t) / ε_t)
```
Dove:
- w_i^(t) = peso del campione i all'iterazione t
- α_t = peso del classificatore debole t
- ε_t = errore ponderato del classificatore t
- h_t(x_i) = predizione del classificatore debole t
- I(·) = funzione indicatore (1 se vero, 0 altrimenti)

AdaBoost aumenta il peso degli esempi predetti erroneamente nelle iterazioni precedenti, aumentando le penalità per quegli errori.
