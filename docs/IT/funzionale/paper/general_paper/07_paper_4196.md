# Estimating The Health of Helicopter Turbine Engines by Means of Regression and Classification Using a Probabilistic Neural Network

## Panoramica del Progetto

Questo documento presenta l'approccio del team Mad SoftMax alla 2024 Data Challenge presentata dalla Prognostics and Health Management Society. La competizione ha incaricato i partecipanti di stimare la salute dei motori a turbina degli elicotteri calcolando il margine di coppia tramite regressione e classificando i motori come sani o difettosi. È stata impiegata la regressione probabilistica per stimare il margine di coppia ad ogni misurazione, e un classificatore basato su rete neurale è stato utilizzato per categorizzare ogni osservazione nel dataset come appartenente a un motore sano o difettoso.

## Problema Affrontato

Il progetto affronta due compiti principali per il monitoraggio della salute dei motori turboshaft degli elicotteri:

1. **Regressione Probabilistica del Margine di Coppia**: stima del margine di coppia espresso come distribuzione di probabilità per ogni punto dati
2. **Classificazione Binaria dello Stato di Salute**: determinazione se il motore è nominale (sano) o difettoso, con assegnazione di una confidenza a quella determinazione

I metodi tradizionali di manutenzione si basano su ispezioni programmate, che possono portare a tempi di inattività non necessari o mancata rilevazione di guasti in fase iniziale. Questo studio propone un approccio basato su reti neurali che utilizza dati operativi per valutare la salute del motore.

## Metodologia

L'approccio proposto utilizza un **sistema integrato di reti neurali** strutturato in fasi chiave:

### 1. Comprensione dei Parametri e Feature Engineering

**Parametri Ambientali**:
- **oat (Outside Air Temperature)**: temperatura dell'aria esterna
- **pa (Power Available)**: altitudine di pressione
- **ias (Indicated Air Speed)**: velocità indicata dell'aria

**Parametri di Performance del Motore**:
- **mgt (Mean Gas Temperature)**: temperatura media del gas
- **np (Net Power)**: potenza netta
- **ng (Compressor Speed)**: velocità del compressore
- **trq_meas (Measured Torque)**: coppia misurata

**Feature Derivata - Coppia Obiettivo**:
La coppia obiettivo (trq_tgt) non era fornita direttamente, ma è stata calcolata manipolando l'equazione del margine di coppia fornita nel problema.

### 2. Modello di Regressione Probabilistica

**Architettura del Modello**:
- **Multi-Layer Perceptron (MLP)** con output probabilistico
- Struttura a 5 layer:
    - **Layer 1**: Input scaling layer (6 parametri)
    - **Layer 2-3**: Hidden layers (256 nodi ciascuno) con funzione di attivazione sigmoid
    - **Layer 4**: Linear scaling layer (2 nodi)
    - **Layer 5**: IndependentNormal layer (da TensorFlow Probability)

**Caratteristiche Chiave**:
- Predice una distribuzione normale anziché un singolo valore
- Output: parametri μ̂_tgt e σ̂_tgt della distribuzione predetta
- Input: oat, mgt, pa, ias, np, ng
- Output: distribuzione normale che predice ˆtrq_tgt (coppia obiettivo predetta)

**Ottimizzatore e Loss Function**:
- **Adam Optimizer** con learning rate decrescente
- **Negative Log-Likelihood Loss Function**: massimizza la probabilità che i punti del training set facciano parte della distribuzione della rete neurale

**Razionale della Distribuzione Normale**:
- Applicazione del teorema del limite centrale (oltre 740,000 punti nel training set)
- Modellazione di tutte le fonti di rumore identificate come distribuzione normale a media zero con deviazione standard σ
- Fonti di inaccuratezza: rumore del sensore, rumore intrinseco al processo, inaccuratezza del modello

### 3. Modelli di Classificazione

Il team ha sviluppato tre approcci diversi per la classificazione:

#### Approccio 1: Metodo Statistico (CDF-based)
- Non utilizza machine learning
- Calcola distribuzioni normali per entrambi i tipi di guasto
- Utilizza funzioni di distribuzione cumulativa (CDF) e funzioni di sopravvivenza
- Semplice ma con troppa ambiguità nella regione di sovrapposizione

#### Approccio 2: Deep MLP
- **Architettura**:
    - **Layer 1**: Input layer (8 nodi) con attivazione ReLU
    - **Layer 2-4**: Hidden layers (20 nodi ciascuno) con attivazione ReLU
    - **Layer 5**: Output layer (1 nodo) con attivazione sigmoid
- **Input**: ˆtrq_mar, trq_meas, oat, mgt, pa, ias, np, ng
- **Ottimizzatore**: Adam
- **Loss Function**: Binary Cross-Entropy
- Configurazione più profonda per promuovere interconnessione più forte dei layer nascosti

#### Approccio 3: Wide (Shallow) MLP - MODELLO FINALE SELEZIONATO
- **Architettura**:
    - **Layer 1**: Input layer (7 nodi)
    - **Layer 2**: Hidden layer (32 nodi) con attivazione sigmoid
    - **Layer 3**: Output layer (2 nodi) con attivazione softmax
- **Input**: ˆtrq_mar, oat, mgt, pa, ias, np, ng (NON include trq_meas)
- **Ottimizzatore**: Adam
- **Loss Function**: Categorical Cross-Entropy
- **Output**: due label (x_n per nominale, x_f per difettoso)
- Sorprendentemente piccolo ma con performance eccellente
- Selezionato perché ha performato meglio sul test set nonostante avesse loss più alta sul training set

### 4. Architettura Integrata Runtime

Il sistema finale combina:
1. **Modello di Regressione**: predice ˆtrq_tgt e calcola ˆtrq_mar
2. **Modello di Classificazione**: utilizza ˆtrq_mar (invece di trq_mar reale) insieme ad altri parametri per classificare lo stato di salute

Questo permette al modello di classificazione di fare predizioni senza accesso a trq_mar reale, con alta accuratezza finché la stima ˆtrq_mar è accurata.

### 5. Training e Testing

**Strategia di Validazione**:
- Split 80-20 dei dati di training (80% training, 20% internal test set)
- Valutazione rapida di nuovi approcci senza attendere il punteggio giornaliero
- Test giornalieri sul test set ufficiale durante la fase di testing

**Processo Iterativo**:
- Training incrementale con aumento graduale di nodi, layer ed epoche
- Riduzione del learning rate man mano che il training procede
- Monitoraggio dell'overfitting confrontando performance su training set e test set
- Selezione del modello basata su performance sul test set (non solo su training set)

**Prevenzione dell'Overfitting**:
- Rilevato overfitting quando i nodi superavano 256 nel modello di regressione
- Modello finale: 256 nodi per la regressione, 32 nodi per la classificazione
- Early stopping implicito basato su performance del test set

## Algoritmi Utilizzati

### Regressione (Stima del Margine di Coppia)

- **Multi-Layer Perceptron (MLP) Probabilistico**
    - Architettura: 6 input → 256 nodi (sigmoid) → 256 nodi (sigmoid) → 2 nodi (linear) → IndependentNormal layer
    - Ottimizzatore: Adam (β₁ = 0.9, β₂ = 0.99)
    - Loss Function: Negative Log-Likelihood
    - Learning Rate: decrescente (10⁻⁴ → 10⁻⁷)
    - Epoche di training: fino a 7,000
    - Output: distribuzione normale N(μ̂_tgt, σ̂_tgt)

### Classificazione (Predizione dello Stato di Salute)

**Modello Finale Selezionato**:
- **Wide (Shallow) MLP con Softmax**
    - Architettura: 7 input → 32 nodi (sigmoid) → 2 nodi (softmax)
    - Ottimizzatore: Adam (β₁ = 0.9, β₂ = 0.99)
    - Loss Function: Categorical Cross-Entropy
    - Learning Rate: 10⁻⁴
    - Epoche di training: 10
    - Output: due probabilità (nominale e difettoso)

**Altri Modelli Esplorati**:
1. **Metodo CDF Statistico**: basato su funzioni di distribuzione cumulativa
2. **Deep MLP**: 8 input → 20 nodi (ReLU) × 3 layers → 1 nodo (sigmoid)

### Funzioni di Attivazione

1. **Sigmoid**: per layer nascosti nel modello di regressione e nel wide classifier
2. **ReLU (Rectified Linear Unit)**: per il deep classifier
3. **Softmax**: per l'output layer del wide classifier
4. **Linear**: per il layer prima dell'output probabilistico

### Librerie e Framework

- **TensorFlow con Keras API**: per la struttura delle reti neurali
- **TensorFlow Probability**: per elementi probabilistici (IndependentNormal layer)

## Formule Matematiche Utilizzate

### 1. **Margine di Coppia (Equazione 1)**
```
trq_mar(%) = 100 × (trq_meas - trq_tgt) / trq_tgt
```
Dove:
- trq_mar = margine di coppia (%)
- trq_meas = coppia misurata
- trq_tgt = coppia obiettivo (design torque)

Questa è la relazione fondamentale fornita nel problema che definisce come la salute del motore è valutata.

### 2. **Coppia Obiettivo (Equazione 2)**
```
trq_tgt = trq_meas / ((trq_mar / 100) + 1)
```

Manipolazione dell'Equazione 1 per calcolare trq_tgt dai parametri forniti nel training dataset. Questo permette di addestrare la rete neurale a predire la coppia obiettivo.

### 3. **Distribuzione Predetta della Coppia Obiettivo (Equazione 3)**
```
ˆtrq_tgt = trq_tgt + N(0, σ²)
```
Dove:
- ˆtrq_tgt = coppia obiettivo predetta come distribuzione
- N(0, σ²) = distribuzione normale a media zero con varianza σ²

Modellazione delle fonti di rumore (rumore del sensore, rumore del processo, inaccuratezza del modello) come distribuzione normale.

### 4. **Funzione di Attivazione Sigmoid (Equazione 4)**
```
φ(x) = 1 / (1 + e⁻ˣ)
```

Utilizzata nei layer nascosti del modello di regressione probabilistica e nel wide classifier. Fornisce output non lineari nell'intervallo (0, 1).

### 5. **Media del Margine di Coppia Predetto (Equazione 5)**
```
μ̂_mar = 100 × (trq_meas - μ̂_tgt) / μ̂_tgt
```
Dove:
- μ̂_mar = media del margine di coppia predetto
- μ̂_tgt = media della distribuzione della coppia obiettivo predetta
- trq_meas = coppia misurata

Conversione della distribuzione della coppia obiettivo predetta in margine di coppia utilizzando il valore atteso (media).

### 6. **Deviazione Standard del Margine di Coppia Predetto (Equazione 6)**
```
σ̂_mar = 100 × σ̂_tgt / μ̂_tgt
```
Dove:
- σ̂_mar = deviazione standard del margine di coppia predetto
- σ̂_tgt = deviazione standard della distribuzione della coppia obiettivo predetta

Calcolo della deviazione standard del margine di coppia scalata relativamente al valore atteso di ˆtrq_tgt.

### 7. **Assunzioni sulla Coppia Misurata (Equazioni 7 & 8)**
```
μ_meas = trq_meas
σ_meas = 0
```

La coppia misurata soddisfa queste condizioni: la sua media è il valore misurato stesso e la sua deviazione standard è zero (valore deterministico, non distribuzione).

### 8. **Funzione di Distribuzione Cumulativa per Motori Nominali (Equazione 9)**
```
F_n(t) = P_n(T_n ≤ t)
```
Dove:
- F_n(t) = CDF per motori nominali
- T_n = variabile casuale distribuita normalmente per motori nominali
- P_n = funzione di densità di probabilità per motori nominali
- t = qualsiasi valore di margine di coppia

La probabilità che il motore sia nominale aumenta all'aumentare di trq_mar.

### 9. **Funzione di Sopravvivenza per Motori Difettosi (Equazione 10)**
```
S_f(t) = P_f(T_f > t)
```
Dove:
- S_f(t) = funzione di sopravvivenza per motori difettosi
- T_f = variabile casuale distribuita normalmente per motori difettosi
- P_f = funzione di densità di probabilità per motori difettosi

La probabilità che il motore sia difettoso diminuisce all'aumentare di trq_mar.

### 10. **Regole di Classificazione CDF-based (Equazioni 11 & 12)**

**Classificazione come Nominale**:
```
F_n(t) > S_f(t)  →  Motore classificato come NOMINALE
```

**Classificazione come Difettoso**:
```
F_n(t) < S_f(t)  →  Motore classificato come DIFETTOSO
```

### 11. **Confidenza del Metodo CDF (Equazione 13)**
```
C = |F_n(t) - S_f(t)| / (F_n(t) + S_f(t))
```
Dove:
- C = confidenza della classificazione
- Valuta a 0 quando entrambe le probabilità sono uguali
- Valuta a 1 quando una delle due è massimizzata

### 12. **Funzione di Attivazione ReLU (Equazione 14)**
```
R(x) = max(0, x)
```

Utilizzata nel deep classifier.
