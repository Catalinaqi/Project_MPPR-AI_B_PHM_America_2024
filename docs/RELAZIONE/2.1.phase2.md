**Conclusioni:**

## 2.2 Descrizione Dati

### 2.2.1 Distribuzione delle Variabili Target

#### `faulty` – Classificazione binaria
- **Sbilanciamento:** rapporto di ≈ **1.48** (60% sani, 40% guasti).
- È uno sbilanciamento **lieve** per il dominio PHM, gestibile senza tecniche aggressive di ricampionamento.

#### `trq_margin` – Regressione (margine di coppia)
- **Media:** 8.11, **Dev. std:** 6.15.
- **Asimmetria (skewness):** **-2.70** (fortemente negativa, lunga coda sinistra).
- **Range:** da **-23.12** a **21.14**.
- **Fitting distribuzioni teoriche (test KS):**
  - Skew-Normal: KS = **0.097** (miglior fit)
  - Normale: KS = 0.164
  - Gamma: KS = 0.250
- La skew-normal descrive meglio la coda sinistra, ma nessuna distribuzione parametrica è perfetta (p-value ~0 a causa della grande numerosità).

| Sensore | Media | Dev. std | Skewness | CV |

  - `pa` > 1.0 → variabilità massima (cambio altitudine in ogni volo).
  - `ng`, `np`, `mgt` → CV < 0.07 → sensori estremamente stabili; piccole deviazioni indicano degradazione.

### 2.2.3 Validazione Fisica vs Limiti Tecnici

I range reali dei dati sono stati confrontati con i limiti ingegneristici del file `ranges_quality_rules_config.yml`.

- **Nessuna violazione** dei limiti fisici per le variabili analizzate (`oat`, `ias`, `pa`, `mgt`, `ng`, `np`, `trq_measured`).
- **Classificazione dinamica per variabilità:**
  - **Contesto Operativo** (CV alto): `pa`, `oat`, `ias`, `trq_measured` → dati da trattenere perché rappresentano condizioni di volo reali (hover, salita, ecc.).
  - **Sensori Interni** (CV basso): `mgt`, `ng`, `np` → alta stabilità; eventuali deviazioni sono segnali di guasto.

### 2.2.4 Verifica Criteri della Pipeline di Qualità

- **Criteri di scarto (anomalie sensore):** nessuna variabile attiva le regole di scarto (es. `mgt` minimo 482.8 > 200°C, `ng` minimo 90 > 60%).
- **Criteri di ritenzione (contesto operativo):** i valori a terra (es. `ias` = 0.0) e le altitudini negative (`pa` = -188.83) sono confermati come fenomeni fisici e devono essere mantenuti nel modello.

## 2.3 Verifica della Qualità dei Dati

### 2.3.1 Collinearità tra Feature

- **Soglia di leakag**e: ±0.95 (nessuna coppia superata).
- **Soglia secondaria di allerta**: ±0.85 (nessuna coppia superata).
- La correlazione più alta: **`ng` vs `np`** = **-0.79** (fisicamente attesa nei transitori).
- Altre coppie: `mgt` vs `trq_measured` = 0.64, tutte entro limiti accettabili.

**Conclusione:** Non vi è multicollinearità problematica. Le feature possono essere utilizzate senza tecniche di riduzione della dimensionalità per questo aspetto.

### 2.3.2 Valori Zero o Negativi

- **`oat`**: 364 record (5.2%) con valori ≤ 0, minimo **-19.0°C**. → Fisiologico (clima invernale o alta quota). **Nessuno scarto.**
- **`ng`**: 0 record anomali, minimo 90.00 → sensore integro.
- Tutte le altre variabili: nessuna segnalazione.

**Conclusione:** I dati non presentano artefatti strumentali. I valori fuori dal range comune sono contesti operativi reali.

## 2.4 Esplorazione dei Dati – Data Drift

### Test di Kolmogorov–Smirnov (KS) sulle Feature

- **Soglia di drift critico**: KS > 0.1 (con p-value 0.0 per tutte le feature).
- **Risultati principali:**

| Feature | KS (Train vs Validation) | KS (Train vs Test) |
|---------|--------------------------|---------------------|
| `np`    | 0.322                    | **0.477** |
| `ng`    | 0.241                    | **0.361** |
| `oat`   | 0.204                    | 0.289 |
| `pa`    | 0.169                    | 0.226 |
| `mgt`   | 0.196                    | 0.201 |
| `ias`   | 0.145                    | 0.175 |
| `trq_measured` | 0.166            | 0.227 |

- **Tutte le feature superano la soglia di 0.1**, indicando un **significativo covariate shift** tra train e test.
- Le variabili di regime (`np`, `ng`) hanno lo shift più marcato (KS fino a 0.48).

**Conclusione:**  
I set di test e validation rappresentano inviluppi di volo diversi dal train set. Questo drift impone l'uso di modelli robusti (alberi, gradient boosting, reti regolarizzate) e suggerisce che il test set costituisce una sfida realistica per la generalizzazione.
