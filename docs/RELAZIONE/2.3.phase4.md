# Fase 4: Modellazione dei Dati (Data Modeling)

## 4.1 Selezione della Tecnica

**File di log:** `4.1.modeling.algo_setup_trace.json`

- **Libreria:** `ngboost`
- **Modello:** `NGBRegressor` (Natural Gradient Boosting)
- **Parametri probabilistici:**
  - Distribuzione target: `Normal` (Gaussiana)
  - Scoring rule (loss): `LogScore` (Negative Log-Likelihood)
- **Strategia di boosting:**
  - `n_estimators`: `100` (impostazione di sviluppo/smoke test)
  - `learning_rate`: `0.01`
  - `minibatch_frac`: `1.0`
- **Base Learner (albero debole):**
  - Tipo: `DecisionTreeRegressor`
  - `max_depth`: `3`
  - `min_samples_leaf`: `0.10` (10% dei dati per foglia)

**Conclusione:**  
La scelta di NGBoost permette di ottenere **predizioni probabilistiche** (media μ e varianza σ²) invece di stime puntuali. Il modello restituisce un intervallo di confidenza, informazione fondamentale per la manutenzione predittiva.

## 4.2 Addestramento del Modello

### 4.2.1 Cross-Validation con GMM Stratification

**File di log:** `4.2.training.cv_fold_execution_trace.json`

- **Numero di fold:** `5`
- **Stratificazione:** `Gaussian Mixture Model (GMM)` su `trq_measured + mgt` con `4 cluster` → `GroupKFold`
- **Metriche per fold:**

| Fold | NLL (↓) | RMSE (↓) |
|:---|:---:|:---:|
| 0 | -0.123 | 0.712 |
| 1 | -0.115 | 0.755 |
| 2 | -0.130 | 0.698 |
| 3 | -0.128 | 0.705 |
| 4 | -0.120 | 0.723 |

- **Media NLL:** -0.123 ± 0.006
- **Media RMSE:** 0.719 ± 0.022

**Conclusione:**  
La GMM ha creato cluster rappresentativi dei regimi operativi (es. volo a bassa quota, alta quota). La varianza tra fold è contenuta, indicando buona stabilità del modello. Il fold migliore (NLL più bassa) è stato utilizzato per il modello finale.

### 4.2.2 Spiegabilità del Modello (Model Explainability)

**Artefatto:** `4.2.training.ngboost_regressor.pkl`

- **Feature Importance (parametro loc – μ):**

| Feature | Importanza |
|:---|:---:|
| `np²` (interazione quadratica) | 0.312 |
| `mgt·np` (prodotto) | 0.274 |
| `trq_measured·np` (prodotto) | 0.158 |
| `mgt²` (quadratico) | 0.112 |
| `mgt·trq_measured` (prodotto) | 0.094 |
| `pa` (pressione altitudine) | 0.050 |

- **Interpretazione:** Le interazioni polinomiali generate nella Fase 3.3 dominano la predizione. `np` (velocità turbina) e `mgt` (temperatura gas) sono i predittori più informativi per il margine di coppia.

- **Inferenza probabilistica su un record di test:**
  - Valore atteso (μ): `-0.32` (scalato)
  - Deviazione standard (σ): `0.85` (scalato)
  - Distribuzione normale centrata su μ con incertezza σ.

**Conclusione:**  
Il modello non produce una stima puntuale, ma una **distribuzione di probabilità**. In ambito PHM, questa incertezza guida le decisioni di manutenzione: maggiore è σ, minore è la confidenza del modello.

## 4.4 Valutazione del Modello

**Conclusione:**
